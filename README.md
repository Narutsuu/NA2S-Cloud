# NACLOUD
Stockage cloud personnel — projet NACORP.
Stack : React + TypeScript (Vite), Firebase (Auth, Firestore, Storage), Vercel.

Test local (optionnel) : copier `.env.example` en `.env.local`, le remplir, puis `npm install` et `npm run dev`.
Règles de sécurité : `firestore.rules` et `storage.rules` (à coller dans la console Firebase).
